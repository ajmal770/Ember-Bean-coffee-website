# AURELIA | Premium Coffee Shop & Restaurant Web Application

Please navigate to the `coffee-shop/` directory for full source code, or refer to [coffee-shop/README.md](file:///d:/Coffee%20Shop%20&%20Restaurant/coffee-shop/README.md) for full architecture details, API documentation, and startup commands.

### Quick Start:

1. **Backend API** (Runs on port 5000):
   ```bash
   cd coffee-shop/backend
   npm run dev
   ```

2. **Frontend UI** (Runs on port 5173):
   ```bash
   cd coffee-shop/frontend
   npm run dev
   ```

### Live Endpoints:
- Frontend: [http://localhost:5173](http://localhost:5173)
- Backend: [http://localhost:5000](http://localhost:5000)
- Health Check: [http://localhost:5000/api/health](http://localhost:5000/api/health)
